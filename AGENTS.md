# NANAGANABA hero

Next.js 16 app — single scroll-driven 3D camera hero at `/` and `/hero-scene`.

## Commands

- `npm run dev` — local dev
- `npm run build` — production build
- `npm run check` — lint, typecheck, build

## Stack

Next.js App Router, React Three Fiber, GSAP ScrollTrigger, Tailwind CSS v4.
